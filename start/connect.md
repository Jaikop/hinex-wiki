# Как подключиться

## Адреса сервера

| IP   | Адрес                        | Назначение |
| ---- | ---------------------------- | ---------- |
| IP 1 | `mc.hinex-server.ru`         | Основной   |
| IP 2 | `hinex.joinserver.xyz`       | Резервный  |
| IP 3 | `hinexreserv.joinserver.xyz` | Резервный  |
| IP 4 | `shield.hinex-server.ru`     | Резервный  |

{% hint style="success" %}
Если основной адрес недоступен или соединение нестабильно — попробуйте один из резервных.
{% endhint %}

## Подключение

1. Запустите Minecraft и откройте список серверов.
2. Нажмите «Добавить сервер».
3. Укажите адрес `mc.hinex-server.ru`.
4. Сохраните сервер и подключитесь.

Доступ к серверу предоставляется по проходке (вайтлисту). Оплата и путеводитель — в [Telegram-боте](https://t.me/hinex_protect_bot), товары — в [магазине](https://shop.hinexpe.ru/).
