# 4. Наказания

## Виды мер

| Мера                      | Описание                                                                 |
| ------------------------- | ------------------------------------------------------------------------ |
| Мут                       | Ограничение на общение в чате.                                           |
| Предупреждение (варн)     | Три активных варна могут стать основанием для постоянной блокировки.     |
| Временная блокировка      | Блокировка аккаунта на определённый срок.                                |
| Постоянная блокировка     | Бессрочная блокировка аккаунта.                                          |
| Аннулирование проходки    | Лишение доступа к проекту (вайтлиста) при особых обстоятельствах.        |
| ЧСП                       | Чёрный список проекта — полный запрет на участие без гарантии амнистии.  |

## Правила

**4.1.** За нарушение правил администрация вправе выдать мут, предупреждение (варн), временную блокировку или постоянную блокировку аккаунта в зависимости от тяжести нарушения.

**4.2.** Получение трёх активных предупреждений (варнов) может являться основанием для выдачи постоянной блокировки аккаунта.

**4.3.** В особых случаях администрация вправе применить более строгое наказание, не ограничиваясь системой предупреждений.

**4.4.** Игрок имеет право подать апелляцию на полученное наказание через официальные каналы поддержки проекта:

* Telegram-бот поддержки;
* сообщения в Telegram-канале проекта;
* Discord-сервер проекта.

**4.5.** При особых обстоятельствах проходка (вайтлист, доступ к проекту) может быть аннулирована по решению администрации.

**4.6.** За грубые, систематические или особо тяжкие нарушения игрок может быть внесён в ЧСП (Чёрный список проекта), что может повлечь полный запрет на участие в проекте без гарантии последующей амнистии.

**4.7.** Многочисленные нарушения одного и того же пункта правил, а также систематическое игнорирование требований администрации могут повлечь за собой выдачу варна или блокировку в зависимости от обстоятельств.

**4.8.** Администрация вправе пересматривать, смягчать или ужесточать наказания с учётом обстоятельств нарушения, истории игрока и иных факторов.
