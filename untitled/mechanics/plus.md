# Возможности Plus

> **Plus** — подписка, которая делает ваш чат и ник ярче.

{% hint style="info" %}
Оформить Plus можно в [магазине](https://shop.hinexpe.ru/).
{% endhint %}

## Что даёт

| Возможность           | Где                                          |
| --------------------- | -------------------------------------------- |
| Эмодзи                | Кнопка «Эмодзи» слева от строки чата         |
| Форматирование текста | Кнопка «Форматирование» слева от строки чата |
| Цвет ника             | Таб                                          |
| Суффикс после ника    | Таб                                          |
| Вход без сообщения    | Никто не увидит «зашёл» и «вышел»            |

## Эмодзи

* Сетка эмодзи и вкладка «Недавние».
* Клик — вставить, **Shift + клик** — вставить несколько подряд.
* Список в чате — `/plus emojis`: клик по эмодзи копирует его код вида `:имя:`.

## Форматирование

* Стили: **жирный**, _курсив_, подчёркнутый, ~~зачёркнутый~~, мерцающий.
* Градиент, плавный переход цветов, тень, «прайд».
* Палитра: любой цвет по HEX, 16 стандартных цветов, недавние.
* Выделите текст и нажмите стиль — он применится к выделенному.
* Над строкой ввода — предпросмотр: как сообщение увидят другие.

{% hint style="warning" %}
Без Plus на кнопках чата висит замочек и подсказка «Нужна подписка Plus».
{% endhint %}

## Ник и суффикс в табе

Откройте меню паузы (**Esc**) и нажмите кнопку с искрой справа от «Вернуться к игре». Там:

* превью вашей строки в табе;
* цвет ника — палитрой;
* суффикс до **35 символов** — с эмодзи и форматированием, как в чате;
* переключатель сообщения о входе.

{% hint style="info" %}
Цвет ника и суффикс видны только в табе — в чате они не меняются.
{% endhint %}

## Команды

Всё то же можно сделать командами:

| Команда                        | Что делает                  |
| ------------------------------ | --------------------------- |
| `/plus setsuffix <текст>`      | Установить суффикс          |
| `/plus setsuffix reset`        | Сбросить суффикс            |
| `/plus setcolor <0-f>`         | Цвет ника из 16 стандартных |
| `/plus setcolor hex <#RRGGBB>` | Любой цвет ника             |
| `/plus setcolor reset`         | Сбросить цвет               |
| `/plus joinmessage off`        | Входить без сообщения       |
| `/plus joinmessage on`         | Вернуть сообщение о входе   |
| `/plus emojis`                 | Список эмодзи               |
