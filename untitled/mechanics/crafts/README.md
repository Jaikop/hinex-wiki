# Крафты и предметы

> На HINEX есть предметы, которых нет в обычном Minecraft. Их рецепты открываются в [древе знаний](../knowledge-tree.md).

{% hint style="info" %}
Рецепт не крафтится и его нет в книге рецептов? Значит, его ветка ещё не изучена — над хотбаром появится подсказка, какая именно.
{% endhint %}
