# Пиротехника I

{% hint style="info" %}
**Ветка** [**древа знаний**](../knowledge-tree.md)**:** 250 ✦ · нужна «[Базовые рецепты](basics.md)»
{% endhint %}

## Детонатор

> Без него не скрафтить динамит.

| Свойство    | Значение                                    |
| ----------- | ------------------------------------------- |
| Зачем       | Ингредиент динамита                         |
| Особенность | Выглядит как книга, но прочитать его нельзя |

**Рецепт** (в любом порядке): 2 сгустка слизи + порох + редстоун.

## Динамит

> На HINEX динамит крафтится только с Детонатором.

**Рецепт:**

```
П Е П
Е Д Е
П Е П
```

П — порох · Е — песок или красный песок · Д — Детонатор

{% hint style="warning" %}
Обычный рецепт динамита (5 пороха + 4 песка) на сервере не работает.
{% endhint %}

## Граната

> Дешёвая и лёгкая взрывчатка: ранит существ, но не разрушает блоки.

| Свойство         | Значение                                     |
| ---------------- | -------------------------------------------- |
| Как использовать | Бросить (ПКМ) или выстрелить из раздатчика   |
| Действие         | Взрыв ранит игроков и мобов, блоки не ломает |
| Перезарядка      | 2 секунды                                    |

**Рецепт:**

```
Н Н Н
Н П Н
Н Н Н
```

Н — железный самородок · П — порох

## Молотов

> Самодельная зажигательная смесь: поджигает всё в месте падения.

| Свойство         | Значение                                                      |
| ---------------- | ------------------------------------------------------------- |
| Как использовать | Бросить (ПКМ) или выстрелить из раздатчика                    |
| Действие         | Поджигает существ в радиусе 2,5 блока на 5 секунд и землю 3×3 |
| Перезарядка      | 2 секунды                                                     |

**Рецепт:**

```
О
Б
```

О — огненный порошок · Б — стеклянный пузырёк
