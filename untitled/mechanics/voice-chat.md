# Голосовой чат

> На HINEX работает голосовой чат **Simple Voice Chat**: игроков рядом слышно, и чем дальше человек, тем тише голос.

## Установка

{% stepper %}
{% step %}
### Скачайте мод

Возьмите Simple Voice Chat для своего загрузчика и версии 26.3 на [Modrinth](https://modrinth.com/plugin/simple-voice-chat).
{% endstep %}

{% step %}
### Положите в `mods`

Рядом с HinexFeatures.
{% endstep %}

{% step %}
### Настройте микрофон

Зайдите на сервер, нажмите **V** и выберите микрофон и громкость.
{% endstep %}
{% endstepper %}

## Управление

| Клавиша     | Действие                                         |
| ----------- | ------------------------------------------------ |
| `V`         | Меню голосового чата: микрофон, громкость, режим |
| `Caps Lock` | Говорить, пока зажата (режим «нажми и говори»)   |
| `G`         | Группы                                           |
| `M`         | Выключить микрофон                               |
| `N`         | Выключить голосовой чат целиком                  |
| `H`         | Скрыть значки голосового чата                    |

{% hint style="info" %}
В меню **V** можно вместо «нажми и говори» включить активацию голосом. Клавиши меняются в «Настройки → Управление».
{% endhint %}

## Группы

Группа — общий канал: участников слышно на любом расстоянии. Нажмите **G**, чтобы создать группу или вступить в существующую — у группы может быть пароль.

{% hint style="warning" %}
Намеренный шум в голосовом чате запрещён — [п. 1.1 правил](../rules/general.md).
{% endhint %}
