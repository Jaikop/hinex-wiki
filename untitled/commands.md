# Все команды

## Чат

| Команда              | Что делает                                                   |
| -------------------- | ------------------------------------------------------------ |
| `!<текст>`           | Сообщение в глобальный чат (без `!` — локальный, 100 блоков) |
| `/msg <ник> <текст>` | Личное сообщение (также `/tell`, `/w`)                       |

## Древо знаний

| Команда     | Что делает                                          |
| ----------- | --------------------------------------------------- |
| `/древо`    | Открыть [древо знаний](mechanics/knowledge-tree.md) |
| `/эссенция` | Ваш счёт ✦ и изученные ветки                        |

## Plus

Только с подпиской [Plus](mechanics/plus.md).

| Команда                        | Что делает                                     |
| ------------------------------ | ---------------------------------------------- |
| `/plus setsuffix <текст>`      | Установить суффикс в табе (`reset` — сбросить) |
| `/plus setcolor <0-f>`         | Цвет ника из 16 стандартных                    |
| `/plus setcolor hex <#RRGGBB>` | Любой цвет ника (`reset` — сбросить)           |
| `/plus joinmessage off`        | Входить без сообщения (`on` — вернуть)         |
| `/plus emojis`                 | Список эмодзи                                  |

## Разное

| Команда     | Что делает                                                             |
| ----------- | ---------------------------------------------------------------------- |
| `/руки`     | Поднять руки — вас можно обыскать ([подробнее](mechanics/features.md)) |
| `/шляпа`    | Надеть предмет из руки на голову                                       |
| `/checkban` | Ваш статус: бан, мут, предупреждения                                   |
