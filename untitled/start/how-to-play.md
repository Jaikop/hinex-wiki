# Как начать играть

{% stepper %}
{% step %}
### Лицензия Minecraft

Нужна лицензионная **Minecraft: Java Edition** версии **26.3**. Без лицензии мод не пустит в игру.
{% endstep %}

{% step %}
### Проходка

Доступ к серверу — по проходке (вайтлисту). Как её получить и оплатить, подскажет [Telegram-бот](https://t.me/hinex_protect_bot) — там же путеводитель по проекту.
{% endstep %}

{% step %}
### Мод HinexFeatures

Без мода сервер не пустит. Скачайте файл для своего загрузчика со [страницы релизов](https://github.com/Jaikop/hinex-features/releases/latest) и положите его в папку `mods`.

| Загрузчик | Что положить в `mods`                         |
| --------- | --------------------------------------------- |
| Fabric    | **Fabric API** и `HinexFeatures-fabric-….jar` |
| NeoForge  | `HinexFeatures-neoforge-….jar`                |
| Forge     | `HinexFeatures-forge-….jar`                   |
{% endstep %}

{% step %}
### Первый запуск

При первом запуске мод:

* скачает обязательный ресурспак HINEX — прогресс виден справа сверху в главном меню;
* покажет правила — отметьте «Я прочитал правила» и нажмите «Принять»;
* добавит сервера HINEX в начало списка серверов.
{% endstep %}

{% step %}
### Заходите!

Откройте «Сетевая игра» — сервера HINEX уже наверху списка, добавлять их вручную не нужно.
{% endstep %}
{% endstepper %}

{% hint style="success" %}
Дальше мод обновляется сам: когда выйдет новая версия, появится окно «Доступно обновление» — нажмите «Обновить и перезапустить».
{% endhint %}

## Не получается зайти?

| Что видите                                | Что делать                                                                                                 |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Окно «Нужна лицензия»                     | Играть можно только с лицензионного аккаунта Minecraft.                                                    |
| Окно «Запрещённые моды»                   | Нажмите «Отключить и перезапустить» — мод выключит запрещённое (например, Freecam) и перезапустит игру.    |
| Окно «Доступно обновление»                | Нажмите «Обновить и перезапустить». В Prism Launcher и MultiMC игра просто закроется — запустите её снова. |
| Кикает через несколько секунд после входа | Проверьте, что мод HinexFeatures установлен и обновлён, а правила приняты.                                 |
| Не пускает на сервер                      | Проверьте, есть ли у вас проходка.                                                                         |

Не помогло — напишите в [поддержку](support.md).
